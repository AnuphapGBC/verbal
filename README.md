# Verbal

A responsive language-tutor marketplace inspired by Preply, built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

Open the local URL printed by Vite (normally http://127.0.0.1:5173).

```sh
npm run build
npm run preview
```

Features include language and price filtering, a tutor carousel, saved tutors, tutor introductions, a date/time picker, and local demo reservations. Saved tutors, profiles, tutor interest, and reservations persist in browser localStorage. All tutor profiles, ratings, and availability are illustrative. Forms do not contact anyone or create real accounts, and no payments are processed.

Portraits load from Unsplash and fonts from Google Fonts. A production launch will need real tutor data, authentication, a database, payments, and scheduling integration.
